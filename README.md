# 💰 Personal Finance Tracker

Managing expenses can be tough, so I built a **Personal Finance Tracker** using **Java** and **JavaFX**! This simple desktop application helps you keep track of your income, expenses, and savings — all in one place.

## 🛠️ Built With
- **Java 17**
- **JavaFX** (GUI)
- **FXML** (for UI layout)
- **SQLite** (optional, if you’ve used a database – remove if not applicable)

## 📦 Features
- Add income and expenses with details
- View financial summary and transaction history
- Categorize your spending
- Real-time balance updates
- Lightweight and user-friendly UI
